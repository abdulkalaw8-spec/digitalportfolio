# IT Technopreneurship Graduate Portfolio

A professional multi-page portfolio template for an Information Technology graduate majoring in Technopreneurship.

## Visual direction
- Light editorial / technical interface
- White, soft-gray and ink-black base
- Cobalt-blue accents
- Layered geometric hero artwork instead of orbital circles
- No grid background
- Subtle cursor glow, hover depth and page transitions
- Responsive navigation

## Pages
Home, About, What I Do, Skills, Projects, Education, Contact.

Replace bracketed placeholders such as `[FULL NAME]`, `[Project Name]`, `[Technology]`, `[School]`, and `[EMAIL]` with the graduate's information.
